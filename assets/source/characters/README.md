# Active character source masters

One source per active artifact, with stable unversioned names. The matching
Markdown file records provenance and the generation prompt where available.
Historical candidates were removed from the working tree and remain in Git.

- [Joss walk](joss_walk.md): original canonical walking style.
- [Joss standing](joss_idle.md): straight-leg source; runtime keeps walking identity.
- [Lucas walk](lucas_walk.md): current normalized candidate; original prompt unavailable.
- [Lucas standing](lucas_idle.md): matching directional standing lower body.
- [Residents](residents.md): Inés, Brais and Alba restyled to compact proportions.

Preparation and runtime addressing are documented in the
[character contract](../../../game/assets/art/characters/README.md).
These source images are offline references; the game imports only normalized
runtime assets. Face/hair/clothing configuration belongs to the requested next spec.
