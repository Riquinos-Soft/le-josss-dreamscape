# References

- [LingBot-Map](https://github.com/Robbyant/lingbot-map): candidate for future offline reconstruction research. Referenced only; not installed, benchmarked, or integrated. Suitability for this Mac and final game assets is unverified.
- Artistic brief: ordinary places gradually become impossible, with stylized geometry, deliberate pixel-scale texture detail, a late-90s computer influence, and atmosphere. Avoid treating a generic low-poly pack or CRT filter as the art direction by itself.
- [Pixel RPG visual reference](dreamscape-pixel-rpg-reference.png), supplied by the developer on 2026-09-25. Use its readable 3/4 character scale, architectural silhouettes, deliberate pixel-scale surface detail, violet/amber light contrast, and individually authored props as direction. It is a reference image, not a screenshot or a ready-to-import asset.

Primary character style reference.
